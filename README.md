# Посмотри в окно

## Как работает приложение

- **Начальная загрузка.** JavaScript запрашивает до пяти карточек, выводит их в правой колонке и подставляет первый
  ролик в плеер.
- **Поиск.** Форма передаёт название города и выбранные параметры времени суток. Список обновляется по результатам
  запроса.
- **Выбор видео.** При нажатии на карточку меняется источник видео, а выбранная карточка выделяется фоном.
- **Догрузка.** Кнопка «Показать еще» появляется, если доступна следующая страница. Новые карточки добавляются в конец
  списка.
- **Обратная связь.** Во время загрузки видны прелоадеры. Пустая выдача и ошибка получения данных показываются в области
  плеера.

Адрес API задан в `BASE_URL` в `scripts/script.js`. Запросы идут на `/api/videos`, а карточки, прелоадеры, кнопку
догрузки и сообщение об ошибке скрипт создаёт из HTML-шаблонов `<template>`.

## Этапы работы

1. **Сетка и видеоблок.** На Flexbox собраны две колонки. Слева расположены плеер и форма, справа — заголовок и
   карточки. У списка своя область прокрутки.
2. **Типографика и карточки.** Оформлены заголовки, описания и миниатюры. `object-fit: cover` заполняет рамки видео и
   изображений с сохранением пропорций. Длинные названия ограничены одной строкой, описания — четырьмя.
3. **Форма.** Оформлены поле города, кнопки и флажки времени суток. Нативный чекбокс остаётся элементом формы, а CSS
   отображает его состояние через `:checked`.
4. **Состояния элементов.** Добавлены стили наведения, нажатия, видимого фокуса с клавиатуры и выбранной карточки.
5. **Загрузка и ошибки.** Через `position: relative` прелоадеры привязаны к контейнерам плеера и списка, а сообщение об
   ошибке остаётся в области видео.
6. **Адрес API.** Обновлён `BASE_URL`, из которого формируются запросы к API и ссылки на медиафайлы.

## Что проверить после запуска

- Выбрать другую карточку и убедиться, что меняется видео.
- Отправить форму с городом или временем суток, затем проверить поиск по вымышленному городу.
- Прокрутить список и при наличии кнопки «Показать еще» загрузить следующую порцию.
- Перейти к полям и кнопкам клавишей `Tab` и переключить чекбокс пробелом.
